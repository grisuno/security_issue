# Repository: lazyaddon

**Description:** Declarative tool and extension manager. Turn any GitHub/GitLab project into an installable, runnable addon from a single YAML file — then use it programmatically, from the lazyaddon CLI, or through a declarative project file. Born from the spirit of LazyOwn's lazyaddons and Estorides' source marketplace: simplify extending a tool
