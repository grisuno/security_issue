# Repository: fakesystemD

**Description:** This project provides a complete, self‑contained emulation of systemd’s D‑Bus interface (`org.freedesktop.systemd1`) and `sd_notify` socket. It allows modern services that expect a full systemd environment to run without modification, even when systemd is not present (e.g., containers, lightweight VMs, or development environments).
